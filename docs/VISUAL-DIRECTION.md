# Rupesh's product and brand notes

Rupesh has confirmed 11 years of experience across creative direction, product design, startup founding and brand strategy. The materials should show how those disciplines affect decisions. Experience is not a substitute for explaining the problem, the competing priorities and the consequence of a choice.

## Content

Start with a specific customer task or team decision. Show the current condition, a possible response and the trade-off. An interface example should expose hierarchy or behavior. A comparison should explain when each response is appropriate. A worksheet should help someone make a decision, with enough room to write and a worked example to clarify the expected answer.

Use hypothetical examples when no real project has been supplied. Label them plainly. Do not invent clients, results, quotes, industries or a portfolio history. The caption carries context; the visual carries the explanation. Every label follows the same plain writing rules as a post, including the ban on long dashes and stock AI phrasing.

## Art direction

Use warm paper, dark ink and a restrained blue accent. Typography has distinct jobs: display type sets the argument, sans serif supports reading and monospace identifies steps and annotations. Align diagrams and tables to a clear grid. Keep strokes, spacing and type sizes consistent within a document.

Covers should contain a visual idea related to the topic, such as a promise-to-task trace or an evidence-to-decision path. Content pages can use annotated interfaces, comparisons, diagrams, matrices and writing fields. Repeat the visual language while adapting the composition to the material.

Inspect complete pages at feed size before scheduling. Check small labels, diagram connections, table cells, writing space, clipping and the sequence across pages. A renderer's successful exit is only a file-generation check; visual review still matters when the design system changes.
